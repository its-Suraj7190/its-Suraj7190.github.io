# 🌐 Suraj Rai – Academic Portfolio Website

## 📖 Overview :

This repository contains the source code for my personal academic portfolio website.

The portfolio showcases my academic journey, mathematical research, software projects, publications, and professional profile. It is designed to provide visitors with a centralized platform to explore my research contributions, open-source software, educational background, and future work.

The website emphasizes a clean and minimal academic design while maintaining responsiveness and ease of navigation.

---

##  ✨ Features : 

* Personal introduction and academic profile
* Educational background
* Research papers with direct Zenodo links
* Software projects with GitHub repositories
* Publication profile through ORCID
* Professional resume
* Responsive and lightweight design
* Smooth navigation between sections
