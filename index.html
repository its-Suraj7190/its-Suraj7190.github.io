  EQ_Solver

📅 2026    • 💻 C    • 📈 Computational tools

A mathematical software that determines the equation of a straight line from two coordinate points and provides geometric analysis.

  Source Code

Overview :

EQ_Solver is a coordinate geometry application that computes the equation of a line passing through two user-defined points. It performs automatic validation of special cases and presents mathematical results in an educational manner.

Features :

  • Accepts any two coordinate points.
  • Computes slope of the line.
  • Generates the equation in slope-intercept form.
  • Handles vertical and horizontal lines correctly.
  • Displays intermediate mathematical calculations.
  • User-friendly command-line interface.

Mathematics Used :

  • Coordinate Geometry
  • Analytic Geometry
  • Straight Line Equations
  • Slope Formula
  • Linear Functions

Algorithms :

  • Euclidian GCD and Slope Calculation algorithm.
  • Special-case detection for undefined slopes.
  • Equation generation using analytical geometry formulas.
  • Input validation.
